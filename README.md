# 경제 지표 대시보드

한국은행 ECOS 와 FRED 데이터를 모아 보는 거시 경제 대시보드입니다.
현재는 **원/달러 환율**만 구현되어 있고, 지표를 추가하기 쉽도록 구조를 잡아 두었습니다.

- **0. 종합 지표** — 지표별 요약 카드(최신값 · 전일대비 · 스파크라인)
- **1. 금리** — 정책금리(한·미·유로) / 한국 단기금리 / 한국 채권금리
- **2. 환율** — 원/달러 · 원/엔(100엔) 매매기준율

화면을 띄워 두면 **5분마다 자동으로 최신 값을 확인**합니다. 탭을 다시 열거나
네트워크가 복구됐을 때도 한 번 더 확인합니다.

## 1. 한국은행(ECOS) API 인증키 발급 — 단계별

매매기준율(한국은행 고시 환율)을 받으려면 ECOS 인증키가 필요합니다. 무료이고, 심사 없이 바로 발급됩니다.

1. **ECOS 사이트 접속** — <https://ecos.bok.or.kr>
2. **회원가입** — 우측 상단 `회원가입`. 이메일 인증까지 완료해야 합니다.
3. **로그인**
4. 상단 메뉴에서 **`오픈API`** → **`인증키 신청`** 으로 이동
5. **신청서 작성**
   - 활용 용도: 예) `개인 학습용 경제지표 대시보드`
   - 사용 URL: 예) `http://localhost:3000` (배포하면 실제 도메인으로 수정)
   - 이메일: 가입한 이메일
6. **신청** 버튼을 누르면 **즉시 발급**됩니다. 발급된 키는
   `오픈API` → `인증키 관리`(마이페이지)에서 다시 확인할 수 있고, 가입 이메일로도 발송됩니다.
7. 발급받은 키를 프로젝트 루트의 `.env.local` 에 넣습니다.

```bash
cp .env.local.example .env.local
```

```dotenv
ECOS_API_KEY=여기에_발급받은_키
```

8. **개발 서버를 재시작**합니다. `.env.local` 은 서버 시작 시점에만 읽힙니다.

> 호출 한도는 **인증키당 하루 100,000회**입니다. 이 앱은 응답을 6시간 캐시하므로
> 개발 중에도 한도에 걸릴 일은 거의 없습니다.

> 키가 없어도 앱은 동작합니다. FRED(뉴욕 종가)만 그려지고, 화면 상단에
> "일부 데이터를 불러오지 못했습니다" 안내가 뜹니다.

### FRED 키 (선택)

지금 화면에는 FRED 데이터가 없지만, 미국 10년물·연준/ECB 정책금리를 붙일 때 쓰려고
클라이언트(`lib/sources/fred.ts`)를 남겨 뒀습니다. `FRED_API_KEY` 는 **없어도 됩니다** —
비워 두면 키가 필요 없는 `fredgraph.csv` 엔드포인트를 씁니다. 공식 JSON API 를 쓰려면
<https://fredaccount.stlouisfed.org/apikeys> 에서 발급받으세요.

## 1-2. Vercel 배포 시 환경변수

**`.env.local` 은 `.gitignore` 에 걸려 있어 GitHub 에 올라가지 않습니다.**
따라서 Vercel 에는 따로 넣어 줘야 합니다.

1. <https://vercel.com> → 해당 프로젝트 → **`Settings`** → **`Environment Variables`**
2. `Key` = `ECOS_API_KEY`, `Value` = 발급받은 인증키
3. 적용 환경은 **Production / Preview / Development 세 개 모두** 체크
4. **`Save`**
5. **`Deployments`** 탭 → 최신 배포의 `⋯` → **`Redeploy`**
   (환경변수는 빌드 시점에 주입되므로, 저장만 하고 재배포하지 않으면 반영되지 않습니다)

> ECOS 인증키 신청서의 "사용 URL" 에 배포 주소(`https://<프로젝트>.vercel.app`)도
> 추가해 두는 편이 안전합니다.

## 3. 데이터 출처

통계표·항목 코드는 ECOS `StatisticItemList` API 로 **실제 응답을 확인한 값**입니다.
(회사채 AA- 는 `010300000` 이고 `010320000` 은 BBB- 라 헷갈리기 쉽습니다.)

| 계열 | 출처 | 식별자 |
|---|---|---|
| 원/달러 매매기준율 | ECOS | `731Y001` / `D` / `0000001` |
| 원/엔(100엔) 매매기준율 | ECOS | `731Y001` / `D` / `0000002` |
| 한국은행 기준금리 | ECOS | `722Y001` / `D` / `0101000` |
| 콜금리(1일, 전체거래) | ECOS | `817Y002` / `D` / `010101000` |
| CD(91일) | ECOS | `817Y002` / `D` / `010502000` |
| 국고채(3년) | ECOS | `817Y002` / `D` / `010200000` |
| 국고채(10년) | ECOS | `817Y002` / `D` / `010210000` |
| 회사채(3년, AA-) | ECOS | `817Y002` / `D` / `010300000` |
| 미국 국채 10년물 | FRED | `DGS10` |
| 미국 연방기금금리(실효) | FRED | `DFF` |
| ECB 예금금리 | FRED | `ECBDFR` |

1995년부터 일별로 받아 오고, 휴장일은 선으로 이어 그립니다.

### 기준금리 카드가 일별 계열을 쓰는 이유

ECOS 의 월별 기준금리(`722Y001` / `M`)는 그 달이 끝나야 채워집니다. 월별을 쓰면
금리를 인상한 날부터 최대 한 달 동안 카드가 옛 값을 보여주게 되어, 값과 날짜는
**일별** 계열에서 가져오고 변화량만 "전월대비"로 계산합니다
(`lib/catalog.ts` 의 `compareMonthsBack`).

### 갱신 구조

```
브라우저 ──5분마다──▶ /api/exchange-rate?since=…  ──▶ ECOS
                         (수백 바이트)                (실제 호출은 10분에 한 번)
```

- 첫 화면은 서버에서 렌더해 바로 보여 줍니다.
- 이후에는 브라우저가 `?since=` 로 **최근 며칠치만** 받아 이어 붙입니다
  (전체 9,800건은 다시 받지 않습니다).
- ECOS 응답은 5년 단위로 나눠서 캐시합니다. 한 번에 30년치를 받으면 4MB 가 넘어
  Next.js 의 fetch 캐시(항목당 2MB) 에 들어가지 않고, 그러면 폴링할 때마다
  한국은행 API 를 그대로 때리게 됩니다. 지난 구간은 30일, 최신 구간만 10분 캐시입니다.
- 결과적으로 방문자가 몇 명이든 외부 API 호출은 **10분에 한 번**입니다.

### 전송량

계열이 12개라 원본 그대로 보내면 브라우저로 수 MB 가 갑니다. 차트가 실제로 그릴 수
있는 점은 화면 폭만큼(약 1,400개)이라, **최근 5년은 일별 원본 그대로**, 그 이전은
LTTB 로 솎아서(`lib/downsample.ts`) 계열당 2,000~2,700점으로 줄입니다.
LTTB 는 균등 간격 샘플링과 달리 1997년 환율 급등 같은 극값을 잘라내지 않습니다.

| | 크기 |
|---|---|
| 첫 로드 (12계열 전체) | 880KB → gzip **110KB** |
| 폴링 1회 (`?since=`) | **약 4KB** |

components/
  Dashboard.tsx             탭 전환 + 폴링 데이터 보유
  LiveStatus.tsx            자동 갱신 상태 표시

  dashboard.ts              모든 계열 조회 (서버 전용)
  downsample.ts             LTTB 해상도 조절
  summary.ts                카드 요약 계산 (서버/클라이언트 공용)
  useLiveDashboard.ts       5분 폴링 훅
  sources/ecos.ts           한국은행 ECOS 클라이언트 (페이지네이션 포함)
  sources/fred.ts           FRED 클라이언트 (JSON API / CSV 폴백)
  series.ts                 기간 필터 · 계열 병합 · 축 눈금 계산
  format.ts                 숫자·날짜 표기

### 지표를 추가하려면

전부 [lib/catalog.ts](lib/catalog.ts) 한 파일에서 끝납니다.

1. `SERIES` 에 계열 정의를 한 줄 추가합니다.
2. 카드가 필요하면 `CARDS` 에, 차트가 필요하면 `CHARTS` 에 참조를 추가합니다.
3. 끝입니다. 조회·캐시·폴링·해상도 조절은 자동으로 따라갑니다.

ECOS 항목 코드는 아래로 조회할 수 있습니다.

```bash
curl -s "https://ecos.bok.or.kr/api/StatisticItemList/$ECOS_API_KEY/json/kr/1/300/817Y002" | jq
```

### 색

계열 색은 `lib/catalog.ts` 의 `COLOR` 에 모여 있습니다.
파랑 `#2a78d6` / 주황 `#eb6834` / 보라 `#4a3aa7` / 빨강 `#e34948` 조합은
색각 이상(적록·청황)에서 서로 구분되는지 검증한 값입니다.

> 참고한 화면은 초록·주황을 같이 썼는데, 그 쌍은 적록색약에서 사실상 구분이
> 안 됩니다(ΔE 3.2). 그래서 초록 자리에 보라를 씁니다.

한 차트에 두 계열 이상이 겹칠 때만 범례를 그립니다(계열이 하나면 제목이 곧 범례).

등락 색은 국내 관행대로 **상승 빨강(`--up`) · 하락 파랑(`--down`)** 이고,
`app/globals.css` 의 CSS 변수로 관리합니다.
